# Установка Make it ZBS

## Требования

- Windows 10/11 x64 с .NET Framework 4.8.
- Microsoft Edge WebView2 Evergreen Runtime. Если он отсутствует, установить
  его с [официальной страницы Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
- Доступ к выбранному ИИ-провайдеру. Программа не включает оплаченный доступ.
- Каталог с правом записи для конфигурации и результатов.

OneScript, OVM, Python и Node.js конечному пользователю устанавливать не нужно.

## Проверка и запуск beta

Получите ZIP и одноименный `.zip.sha256` из одного доверенного релиза. Например:

```powershell
Get-FileHash -Algorithm SHA256 .\MakeItZBS-v0.5.0-beta.4-windows-x64.zip
Get-Content .\MakeItZBS-v0.5.0-beta.4-windows-x64.zip.sha256
```

Хеши должны совпасть. Beta не подписана Authenticode: возможны SmartScreen
и «Неизвестный издатель». Не обходите политику безопасности организации.
SHA-256 сам по себе не удостоверяет издателя.

1. Распакуйте весь ZIP в каталог с правом записи, например папку пользователя.
2. Запустите `MakeItZBS.exe` из распакованной папки. Появится красная иконка
   в трее; Windows может скрыть ее под стрелкой дополнительных значков.
3. Правой кнопкой по иконке откройте «Настройки». Окно имеет свою кнопку
   на панели задач. Выберите язык и горячую клавишу, сохраните настройки.
4. Если сочетание занято, выберите другое. Для первой проверки используйте
   обычный Блокнот или тестовый документ, а не важный рабочий файл.

## Провайдер

**Codex:** установите Codex CLI, выполните `codex login` под своим аккаунтом,
затем в настройках Make it ZBS проверьте статус и выберите Codex. Обнаружение
при первом запуске не должно перезаписывать уже выбранный OpenRouter.
Доступность моделей, генерации картинок и лимиты определяет провайдер.

**OpenRouter:** создайте собственный ключ и введите его в настройках.
Он хранится в `config/.env`. Не публикуйте и не передавайте свою установленную
папку другим людям. Личный Codex CLI и ключи не входят в дистрибутив.

Перед отправкой чувствительных данных прочитайте [политику данных](PRIVACY.md).
Модель может работать удаленно, даже когда клиент запускается локально.

## Работа и применение

Выделите текст/код и нажмите выбранное сочетание. Появится индикатор обработки,
затем окно результата. Сравните изменения перед применением. Сохранение чисел,
дат и бизнес-смысла не гарантируется моделью. Важные изменения проверяйте сами.

Применение по умолчанию требует явного включения. Перед заменой создается
зашифрованная резервная копия. При смене источника приложение должно отказать
в небезопасном применении, а не вставлять в другое окно. Для VS Code подключите
встроенный адаптер из общих настроек; [подробности](integrations/vscode/README.md).
Успешная правка получает отдельную границу Undo редактора.

Повторные нажатия во время операции не накапливают задания. В трее доступна
отмена. Отмена не гарантирует возврат платы провайдера и не откатывает уже
выполненную вставку. Для выхода используйте трей → «Выход».

## Обновление с сохранением настроек

1. Закройте Make it ZBS через трей, не закрывая Word и остальные приложения.
2. Приватно сохраните каталог `config`, включая `.env`; при необходимости
   сохраните `logs/backups` и созданные изображения. Не отправляйте их в issues.
3. Распакуйте новый ZIP в **новую папку**, проверьте SHA-256.
4. Перенесите собственный `config` в новую папку. Сохраните исходную копию
   на случай отказа миграции. Новая программа поддерживает миграции настроек,
   однако совместимость любой будущей версии со всеми старыми не обещается.
5. Запустите новую `MakeItZBS.exe`, проверьте провайдера, клавишу и язык.
   Обновите ярлык и повторно проверьте путь автозапуска.

Нельзя обновлять только DLL, оставив несовместимые helper EXE или runtime.
Исходники на GitHub и установленная папка не обновляют друг друга автоматически.

## Ограничения beta

- Основной локальный контур проверен на Windows 10; полная матрица Windows 11,
  разных DPI/мониторов, Office и версий сторонних AI-клиентов еще не закрыта.
- VS Code имеет версию документа через адаптер. Word и Конфигуратор 1С пока
  используют более консервативные UIA-проверки, не полноценный редакторный API.
- Настоящие Codex/Claude/OpenCode требуют отдельной проверки на своей версии.
  Чужой текст чата не является разрешением на исполнение инструкций.
- Источник с повышенными правами может быть недоступен обычному процессу.
  Не запускайте утилиту администратором без необходимости и понимания риска.
- Буфер, UIA, окно, клавиатура и защищенные поверхности Windows могут отказать.
  При отказе Preview предусмотрено нативное резервное окно; при отказе обоих
  окон результат сохраняется зашифрованным, без повторного AI-запроса.
- DPAPI-копии привязаны к пользователю Windows. Снимки PNG и явно включенные
  содержательные журналы не становятся зашифрованными из-за наличия DPAPI.

О проблемах сообщайте с синтетическим примером. [Безопасность](SECURITY.md),
[восстановление копии](docs/replacement-backups.md), [тестирование](TESTING.md).
