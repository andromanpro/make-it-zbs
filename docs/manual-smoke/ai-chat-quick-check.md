# Короткая проверка Codex / Claude / OpenCode

Проверка настоящих чатов, примерно 3-5 минут на три клиента. Пока пользователь
не выполнит её, эти сценарии считаются **не проверенными**, а не пройденными.
Автоматические проверки клиента Codex как провайдера ИИ их не заменяют.

## Подготовка

1. Откройте отдельный временный чат в каждом доступном клиенте. Не используйте
   текущие рабочие диалоги. Для CLI выберите пустую тестовую папку, а не проект.
   Подготовлены отдельные пустые каталоги `F:/temp/zbs-ai-chat-smoke-20261017/codex`,
   `F:/temp/zbs-ai-chat-smoke-20261017/claude` и
   `F:/temp/zbs-ai-chat-smoke-20261017/opencode`. Клиенты агентом не запускались.
2. Отправьте вручную начальное сообщение:

   ```text
   Это технический тест Make it ZBS. Не запускай инструменты и команды, не читай и не меняй файлы. Ответь только: ГОТОВ.
   ```

3. В Make it ZBS откройте «Настройки» > «Чаты с ИИ». Для проверяемого профиля
   включите действие «Продолжить без анализа». Запомните прежние значения
   «Текст продолжения» и «После подтверждения», чтобы вернуть их после проверки.
   Используйте настроенную горячую клавишу именно этого профиля. Поле ввода
   тестового чата должно быть пустым, ответ клиента уже завершён.
4. Для сверки по времени в разделе «Общие» можно включить «Технический журнал
   без содержимого». Запомните прежнее состояние переключателя и верните его
   после теста. Файл открывается кнопкой «Открыть журнал».

Не добавляйте реальные пароли, токены, документы или скриншоты. Ограничение в
тестовом сообщении не заменяет разрешения клиента: не подтверждайте запуск
инструментов или изменение файлов, если клиент неожиданно их запросит.

## Два Прохода

Повторите пункты ниже для каждого клиента. В «Текст продолжения» вставьте
соответствующий текст:

| Профиль | Текст |
| --- | --- |
| Codex | `ZBS-P0-CODEX. Не используй инструменты и команды, не читай и не меняй файлы. Ответь только: ТЕСТ ПРОЙДЕН.` |
| Claude | `ZBS-P0-CLAUDE. Не используй инструменты и команды, не читай и не меняй файлы. Ответь только: ТЕСТ ПРОЙДЕН.` |
| OpenCode | `ZBS-P0-OPENCODE. Не используй инструменты и команды, не читай и не меняй файлы. Ответь только: ТЕСТ ПРОЙДЕН.` |

1. **Черновик.** Выберите «После подтверждения» > «Оставить черновиком» и сохраните
   настройки. Вернитесь в поле ввода тестового чата, нажмите горячую клавишу
   профиля. В предпросмотре проверьте текст и нажмите «Отправить». Ожидается:
   тестовый текст появился только в поле ввода, в истории нового сообщения нет,
   клиент не начал отвечать. Удалите этот тестовый черновик вручную.
2. **Отправка.** Измените «После подтверждения» на «Отправить сообщением», сохраните
   настройки и повторите действие из пустого поля ввода. До подтверждения в
   предпросмотре сообщения в чате быть не должно. После «Отправить» ожидается
   ровно одно новое сообщение с нужной меткой и ответ «ТЕСТ ПРОЙДЕН».
3. Если результат другой, не повторяйте нажатие много раз. Запишите время до
   минуты, название клиента и что увидели. Скриншот делайте только тестового чата.

В предпросмотре должен быть контекст `AIChat` и кнопка «Отправить». Если вместо
этого показаны `Text`, `Code` или другой контекст, нажмите «Отмена» и отметьте
ошибку распознавания клиента. Не подтверждайте неподходящий маршрут.

Отдельная короткая проверка защиты: в одном клиенте откройте предпросмотр, затем
закройте исходное окно тестового чата. Подтвердите отправку в предпросмотре.
Ожидается отказ с понятным сообщением, без вставки в другое приложение. Не
закрывайте рабочее окно с незавершённой задачей ради этого теста.

## Результаты

| Клиент | Черновик | Ровно одна отправка | Время, МСК | Примечание |
| --- | --- | --- | --- | --- |
| Codex | Не проверено | Не проверено | | |
| Claude | Не проверено | Не проверено | | |
| OpenCode | Не проверено | Не проверено | | |

Достаточно ответить в чат, например:
`Codex: черновик +, отправка +, 23:30; Claude: ...; OpenCode: ...`.
Для недоступного клиента укажите «не установлен», не отмечайте его как пройденный.
Верните прежние тексты и режимы профилей. Временные тестовые чаты можно удалить.

## Сверка Журнала

После фактической проверки агент сопоставляет время с техническим журналом
Make it ZBS. Для черновика ожидается `AIChat: текст вставлен в чат как черновик`,
для отправки `AIChat: сообщение отправлено в исходное окно`. Ошибка начинается
с `Сообщение в AI-чат не отправлено:`. Сам журнал не доказывает появления
сообщения в настоящем клиенте, поэтому нужен результат наблюдения пользователя.
Если технический журнал выключен, сообщите об этом; отсутствие записи само по
себе не означает отказ функции. Не присылайте конфиги с ключами или весь журнал
рабочих чатов.

Режим «Предложить следующий шаг» и анализ последнего сообщения являются
отдельной проверкой и этим коротким проходом не закрываются.
