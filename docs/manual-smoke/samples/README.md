# Примерные материалы для owner-smoke v0.5

| Файл | Контекст | Что должен показать результат |
|---|---|---|
| `text-rough-ru.txt` | Text | Улучшение структуры без выдумывания фактов |
| `code-buggy.js` | Code | Исправление off-by-one и осмысленные `let`/`const` |
| `email-draft-ru.txt` | Email | Деловой тон с сохранением даты и обязательств |
| `excel-sales.tsv` | Excel | Отрицательная маржа и аномальный возврат |
| `ai-chat-transcript.txt` | AIChat | Следующий шаг и локальное маскирование секретов |
| `onec-module.bsl` | OneCCode | Захват модуля и безопасная правка кода 1С |
| `browser-dashboard.html` | Browser | Vision-анализ двух заметных аномалий |
| `paint-cabin-sketch.png` | Image/Paint | Сохранение композиции при переходе к фотореализму |

Файлы содержат только синтетические данные. Настоящие токены, переписку и
рабочий код для smoke не использовать.

`paint-cabin-sketch.png` создан встроенным imagegen как намеренно грубый
MS Paint-вход: дом, озеро, горы, солнце и две сосны. Успех определяется не
похожестью пиксель-в-пиксель, а сохранением этих объектов и общей композиции.
