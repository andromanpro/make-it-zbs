# Make it ZBS

![Make it ZBS: красная кнопка](docs/images/wiki-hero-magic-button.png)

Контекстный ИИ-помощник для Windows: выделить текст или код, нажать **Ctrl+F12**,
проверить результат и при необходимости применить его в исходном приложении.
Приложение работает из трея. Интерфейс: русский и английский.

**Статус: beta.** [Скачать v0.5.0-beta.4](https://github.com/andromanpro/make-it-zbs/releases/tag/v0.5.0-beta.4)
для внешнего тестирования. [Инструкция со скриншотами](docs/USER-GUIDE.md).
Beta распространяется без Authenticode. SHA-256 проверяет целостность,
но не заменяет проверку издателя.

## Что умеет

- Текст, письма, выделенные ячейки Excel, код и модули Конфигуратора 1С.
- Preview с исходником, результатом, сравнением и предупреждением об изменении
  чисел/дат. Применение является отдельным действием пользователя.
- Проверка исходного окна и выделения; для VS Code встроен устанавливаемый
  адаптер с проверкой URI/версии документа и отдельной границей Undo.
- Снимки браузера и изображений; Paint-набросок можно передать провайдеру
  генерации изображений. Качество и доступность зависят от провайдера.
- Профили Codex, Claude и OpenCode: продолжение чата или вставка черновика.
  UI Automation и распознавание клиента имеют ограничения, не все версии проверены.
- Локальный Codex CLI с собственной авторизацией пользователя либо OpenRouter.
  Модель и reasoning настраиваются по контекстам. Локальный CLI не означает
  локальную модель или отсутствие лимитов подписки.
- Отмена принадлежащих операции запросов/процессов, защита от повторных нажатий,
  индикация обработки и времени. Пока одна операция, не очередь разных задач.
- Зашифрованные DPAPI-копии перед заменой и резервный показ результата без WebView.

## Начать

1. Получить ZIP и `.zip.sha256` из согласованного beta-релиза, сверить хеш.
2. Распаковать **всю папку** в каталог с правом записи, запустить `MakeItZBS.exe`.
3. В трее открыть настройки, выбрать провайдера и горячую клавишу.
4. Выделить синтетический текст, нажать сочетание, проверить Preview.

Пользователю не нужны OneScript, Python, Node.js или OVM. Нужны Windows 10/11,
.NET Framework 4.8 и WebView2 Evergreen Runtime. Для Codex дополнительно
устанавливается CLI и выполняется личный вход `codex login`.

## Сборка

Ядро: **OneScript 1.9.4**. Windows-интеграция: C# **net472**, WinForms,
WebView2, UI Automation, отдельные ProcessHost и CaptureHost (DXGI/GDI).
Глобальный OneScript и внешние opm-библиотеки не используются.

На Windows установить Git, .NET SDK **10.0.103**, Node.js **24.12.0**,
Python **3.14.2** и выполнить из Git checkout исходников (не из portable-папки):

```powershell
./tools/ci.ps1 -VerifyReleaseDll
py -3.14 tools/build-release.py --version v0.5.0-beta.4
py -3.14 tools/verify-dist.py dist/MakeItZBS --run-probe
```

Для release требуется чистый Git checkout. `--allow-dirty` предназначен только
для локальной диагностики, не для публичной beta. Архив приватного runtime,
его исходники и лицензия находятся в `vendor/onescript`. Проверка не изменяет
установленную копию, личные настройки или глобальный OVM.

Перед выпуском обязателен также интерактивный прогон на разблокированном
рабочем столе. Публичный headless CI не подменяет проверку Word/Paint/горячих
клавиш, настоящих AI-клиентов и разных мониторов. Известные ограничения
перечислены в [инструкции](INSTALL.md).
