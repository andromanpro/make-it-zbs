# Make it ZBS: адаптер VS Code

Адаптер даёт Make it ZBS проверяемую замену выделения или модуля через API
редактора. Это не провайдер ИИ и не расширение для запуска запросов к модели.
Текст не отправляется по сети расширением. Временная привязка хранит только
URI, версию документа, границы выделения и SHA-256. Срок привязки: 10 минут;
каждая попытка применения расходует её, включая отказ.

## Установка

В Make it ZBS откройте «Настройки > Общие», блок VS Code, и нажмите
«Подключить». Приложение само обнаружит локальный редактор, установит
встроенный пакет и проверит результат. Скачивать или выбирать VSIX не нужно.
Если показан статус о перезапуске окна VS Code, перезагрузите окно редактора.
Более новая установленная версия адаптера не понижается автоматически.

Пакет встроен в DLL приложения. Для установки используется официальный
локальный CLI VS Code в отдельном процессе без консольного окна, с ограничением
времени. Код приложения не исполняет содержимое `code.cmd`: из него извлекается
и проверяется путь штатного CLI, включая каталог с номером сборки редактора.
Изменение окружения Electron ограничено приватным дочерним процессом.

Расширение работает в Windows, в локальном UI extension host, в том числе
при удалённом workspace. Встроенная настройка предназначена для стандартного
локального профиля VS Code. Другой профиль или отдельную установку редактора
можно подключить вручную: Extensions > Install from VSIX, файл
`adapters/make-it-zbs-editor.vsix` из дистрибутива. Отключённое пользователем
расширение приложение принудительно не включает.

Для разработчика: `py -3.14 tools/build-vscode.py`, затем установка файла из
`artifacts/adapters/`. Обычная C#-сборка создаёт этот пакет автоматически
перед встраиванием. ZIP воспроизводим побитово при одинаковых исходниках,
чтобы не менять хеш Release DLL при каждой сборке. Ничего не публикуется
в Marketplace. При изменении поведения расширения повышайте его версию.

## Поведение

Перед генерацией Make it ZBS закрепляет исходник. При «Заменить» расширение
проверяет активное окно, URI, версию, весь документ и диапазон выделения.
Переключение вкладки, правка (даже с последующей отменой), сдвиг выделения
или потеря фокуса запрещают замену. Результат остаётся доступен для копирования.
Успешная замена выполняется через `TextEditor.edit` с отдельной границей Undo.
Множественное выделение не поддерживается. Лимит документа: 1 млн символов.

Связь локальная: именованный канал Windows с одноразовым для сеанса секретом
в профиле пользователя `%LOCALAPPDATA%/MakeItZBS/EditorBridge`. Клиент сверяет
PID сервера и исполняемый файл редактора. Секрет не следует публиковать.
Это граница между приложениями текущего пользователя, не изоляция от вредоносного
процесса с доступом к этому же профилю. Отмена не откатывает уже завершённую правку.

Без установленного адаптера остаётся консервативная проверка через UI Automation.
Она не даёт версии документа от редактора. Если работающий адаптер отклонил
привязку, приложение не обходит отказ через UI Automation.

Выпущенная beta.3 ещё не содержит этот адаптер. Расширение предназначено для
новой сборки, описанной в отчёте от 12.10.2026.
